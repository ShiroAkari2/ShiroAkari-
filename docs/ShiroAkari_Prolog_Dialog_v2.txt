# FORMAT (sesuai parser game di game.gd):
#   [id_dialog]          -> awal satu blok dialog
#   Nama: teks           -> satu baris dialog (pemisah pertama adalah ":")

#   # ...                -> komentar, diabaikan game. Dipakai untuk stage direction.

# CATATAN:
# - Sistem pilihan dialog belum ada. Blok berawalan [pro_malam_A] dan [pro_malam_B] disiapkan
#   untuk nanti. Sampai sistem itu dibuat, game memakai [pro_malam_A] saja.
# - Nama adik: Rian (sementara).
# - Blok sena, dion, elda, marla yang sudah ada di id.txt tetap dipakai; blok ch1_* di bawah
#   adalah versi Chapter 1 yang menyambung ke sana.
